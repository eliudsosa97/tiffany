# Tiffany

Juego de terror y sigilo para la Spooky Game Jam de Hybridge (26 al 30 de octubre de 2026).

Es Día de Muertos. Eres Tiffany, el alma de una niña que despierta en un cerro sin saber que está muerta. Hace un año se la llevó la bruja del cerro, y esta noche sale a buscarla otra vez. Volando, como bola de fuego, ve tu luz. En el suelo oye tus pasos y se lanza sobre ti. Sube a oscuras con Tyler, tu perro, recupera tus recuerdos y guía a tu familia hasta la verdad.

- Unity 6.3 (`6000.3.27f1`) con URP.
- Se juega en el navegador, en itch.io.
- Diseño: [docs/GDD.md](docs/GDD.md).

## Controles

WASD para moverte, Ctrl para ir despacio y Shift para correr. Con el ratón apuntas la luz, F la prende o la apaga y el clic izquierdo lanza un destello. Espacio para esconderte e interactuar, Tab para el cuaderno de recuerdos y Esc para pausar. También se juega con control.

## Abrir el proyecto

Necesitas unos 20 GB libres.

1. Instala [Unity Hub](https://unity.com/download) y activa la licencia Personal.
2. Instala Unity `6000.3.27f1` con Web Build Support. Tiene que ser esa versión exacta. Si no aparece, búscala en la pestaña Archive.
3. Clona el repo y ábrelo en Unity Hub con Add project from disk. La primera vez tarda unos minutos.

La escena principal se genera por código. Ver [AGENTS.md](AGENTS.md).
