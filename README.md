# El Velador

Juego de terror y sigilo para la Spooky Game Jam de Hybridge (26 al 30 de octubre de 2026).

Es Día de Muertos. Eres el alma de una niña que despierta en un cerro sin saber que está muerta. Hace un año se la llevó la bruja del cerro, y esta noche sale a buscarla otra vez: volando como bola de fuego ve tu luz, y en el suelo oye tus pasos y se lanza sobre ti. Sube a oscuras con Tyler, tu perro, recupera tus recuerdos y guía a tu familia hasta la verdad.

- Motor: Unity 6.3 LTS (`6000.3.27f1`) con Universal Render Pipeline.
- Plataforma: navegador (WebGL), publicado en itch.io.
- Diseño completo: [docs/GDD.md](docs/GDD.md).

## Controles

WASD para moverte, Ctrl para caminar despacio, Shift para correr, el ratón para apuntar la luz, F para prenderla o apagarla, clic izquierdo para el destello, Espacio para esconderte e interactuar, Tab para el cuaderno de recuerdos y Esc para pausar. También se juega con control.

## Abrir el proyecto

Necesitas unos 20 GB libres.

1. Instala **Unity Hub** desde [unity.com/download](https://unity.com/download), inicia sesión con una Unity ID y activa la licencia Personal.
2. Instala el editor **`6000.3.27f1`** exacto (si no aparece, búscalo en la pestaña Archive) con el módulo **Web Build Support**. Con otra versión Unity convierte el proyecto y genera conflictos.
3. Clona el repo con GitHub Desktop o con `git clone`.
4. En Unity Hub: Projects, Add, Add project from disk, y elige la carpeta clonada. La primera importación tarda varios minutos.

La escena principal se genera por código. Ver [AGENTS.md](AGENTS.md).
